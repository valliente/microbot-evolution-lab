# Microbot Evolution Lab - Release Notes

## Version 0.1.205 (Production Release)
- **Web Worker Multi-Threading & OffscreenCanvas**: Offloaded Quadtree physics, DNA crossover, and spatial collision lookups to dedicated background threads.
- **Epigenetic Gene Expression**: Starvation and hazard exposure accumulate epigenetic stress triggering adaptive trait expression.
- **Symbiosis & Parasitism Engine**: Non-predator microbots form symbiotic energy-sharing pairs; parasitic entities siphon host energy on contact.
- **3D Genetic Constellation Map**: Interactive rotating 3D species clustering map with one-click PNG snapshot export.
- **Performance Diagnostics Overlay**: Real-time FPS, entity counters, and memory object pool telemetry.
- **Standalone Windows Executable**: Bundled with native Edge App Mode launcher (`MicrobotEvolutionLab.exe`).
